TALEND CV
===============

1. Unzip the package.
2. To test without Talend: open WEB/index.html.
3. The PAUSE button lets you pause ;)
4. At the end, the PDF and ZIP versions are available.
5. For the actual Talend job, follow the instructions in TALEND/JOB_CONSTRUCTION.txt.

The data is separated from the front end:

    DATA/profile.js
    DATA/skills.js
    DATA/experiences.js
    DATA/education.js

To add a new resume version:

- Place the PDF in CV/PDF/
- Add its link to WEB/index.html
- Include the file in the ZIP package.
